# Agent Note: 在插件边界内深化用量仪表盘

Status: implemented

[English](2026-08-15-settings-usage-dashboard-depth.md) | 中文

## Problem

用量仪表盘（[2026-08-14-settings-usage-dashboard.md](2026-08-14-settings-usage-dashboard.md)）只读取每行 `session.list` 的 `tokenUsage` 投影：会话在明细里显示尾部 id 占位符而非标题，上下文占用与构成投影未被使用，页面也无法对所展示的内容采取行动（不能跳转会话、不能导出、没有持续刷新）。用户还看不到哪些会话接近上下文窗口上限、子代理贡献了多少用量。

## Decision

所有骨架包保持不变——不加宿主 RPC、不加 wire 字段、不改 token-meter、不改设置外壳。全部增量都留在 `@deepseek-ai/dsh-client-ui-settings-usage` 内，只消费现有 `session.list` 行契约已经携带的数据。

消费行上其余的持久投影与字段：`title`（明细中的真实会话名）、`contextPressure`（每会话上下文占用条，达窗口 80% 告警，总量中计入接近上限数）、`contextBreakdown`（启发式的系统提示词 / 工具 / 对话构成面板，汇总自带该值的会话）、`running` 与 `origin: 'subagent'`（行徽标与子代理占比卡）、`agentPreset`（副标题片段）。

在 `usage-math.ts` 中以纯函数派生更丰富的分析：今日与近 7 天卡片、活跃天数与连续活跃、最繁忙一天与热力格、每桶缓存命中率序列、自动选择的洞察（缓存命中率健康度、周环比、接近上限会话、子代理占比、最繁忙时段，以严重度色点渲染），以及会话明细的 RFC 4180 CSV 序列化。

在既有插槽条目内扩展展示：趋势图新增总量 / 输出 / 缓存命中率指标切换（命中率模式在固定 0–100% 轴上绘制每桶折线）；明细新增文本过滤、用量 / 最近排序与点击跳转（inject face 仅在可选 `sessions` 服务存在时暴露 `openSession`，点击后经外壳的 `close` owner prop 关闭面板）；工具栏新增 30 秒静默自动刷新开关与 CSV 导出；首次挂载渲染骨架屏；UI 语言为中文时卡片紧凑数值切换为万 / 亿。

将页面的纯中文文案同时注册到两个内置语言席位（`{ zh, en: zh }`）：类型化的 `register` 重载继续校验合并后的 key 联合，任何语言切换都不会出现裸 key。

## Alternatives considered

- **带每次调用事件的宿主用量 RPC** —— 否决：现有投影 seam 已携带这些功能所需的全部数据，为可选浏览器页面新增 wire 表面会修改骨架包。
- **可配置单价的成本估算** —— 否决：仓库中不存在价格数据源，编造单价会把虚构呈现为实测。
- **客户端伪造每次请求的时间戳** —— 否决：列表契约每行只有一个 `updatedAt`，虚构请求历史会歪曲数据。
- **放弃 `LocaleNamespaceMap` 合并、只注册单语言** —— 否决：非类型化注册会失去编译期 key 联合检查；让 zh 词典占住两个席位既保留检查又保持文案单一来源。

## Consequences

仪表盘现在能在一页内回答"哪个会话、哪个项目、哪个时段、上下文多满"，且仍可从组合中移除而不触碰外壳。上下文占用条与构成面板是提示性的：它们是最后写入的投影与估算器启发式，已在 README 限制中如实标注。跳转会话入口在缺少 sessions 服务的组合中静默隐藏。纯中文决定意味着英文语言读者在本页看到中文；如需回退，只需改动一行词典注册。

## Testing

- 包测试覆盖新投影消费（标题、上下文值、来源、running、preset）、派生计算（连续活跃、最繁忙日 / 格、洞察、CSV、本地化紧凑数字）、全部新渲染行为（洞察、指标切换、上下文面板、热力峰值、过滤 / 排序 / 徽标 / 占用条、跳转会话、CSV 导出成功与失败、自动刷新、骨架屏、locale 数字）以及 `apply` 中的 sessions face 装配。
- `src/client` 的每文件分支 / 语句覆盖率保持 100%。

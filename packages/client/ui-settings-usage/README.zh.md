# @deepseek-ai/dsh-client-ui-settings-usage

[English](README.md) | 中文

用量统计设置页：一个完全由可选浏览器插件实现的只读、尽力统计仪表盘。它读取现有的 `session.list` 响应，在有数据时使用每个可见会话持久化的 `tokenUsage` 投影，并通过 `settings.section` 插槽注册页面；不会增加宿主 RPC，也不会修改设置骨架。

页面以统计卡片开场（总量、未缓存输入、输出、缓存读取、缓存写入、缓存命中率、已知调用、会话数），随后是两根百分比单柱图：token 构成柱 —— 已上报总量按四个计费桶拆分，每段按占比定宽；以及提示词缓存命中率柱（缓存读取 vs 提示词流量的其余部分）。悬停色块或柱子即可看到精确数值与百分比。再往下是趋势图（按本地日 / 周 / 月堆叠的 token 用量，叠加 7 日移动平均与峰值标记；日粒度还会把最近一周与上一周对比成涨跌标签）、时段活跃度热力图、以及明细列表（按工作区、按会话，每行带迷你堆叠条、缓存率与已知调用数）。

报告是现有会话列表行的纯函数：插件在浏览器中聚合累计投影，用每个会话的 `updatedAt` 作为本地趋势和热力图的一次活跃标记，并把有非零用量的会话计为至少一次已知调用。页面没有写入路径，也没有推送失效；首次挂载、手动刷新与连接重置后重新加载。

## Model Experience

无；本页是浏览器配置界面，不会向模型请求注入任何内容。

#### KV Cache effect

无；本包既不组装也不发送任何 provider 请求。

## Known Limitations and Deferred Work

- **只统计可见的 `session.list` 行** —— 未挂载 `tokenUsage` 投影，或某行没有投影值时，该行按零计入，不会触发历史读取。
- **时间视图是提示性的，不是请求历史** —— 现有列表契约只有累计总量和一个 `updatedAt`，因此插件把会话总量放到这个活跃标记上，不虚构每次调用的时间。
- **已知调用是下限** —— 有非零用量的会话计为一次调用；现有投影没有精确调用数、回合数、步骤数和模型耗时，因此这些值为零或不可用。
- **用量数据不携带模型维度** —— `tokenUsage` 投影不包含模型或 provider，仪表盘无法进一步拆分；会话与工作区是能提供的最细粒度。
- **缓存命中率是单一聚合值** —— 所有纳入会话的提示词侧占比，而非按请求的分布。

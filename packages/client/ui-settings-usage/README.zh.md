# @deepseek-ai/dsh-client-ui-settings-usage

[English](README.md) | 中文

用量统计设置页：一个完全由可选浏览器插件实现的只读、尽力统计仪表盘。它读取现有的 `session.list` 响应，在有数据时使用每个可见会话的持久投影（`tokenUsage`、`title`、`contextPressure`、`contextBreakdown`），并通过 `settings.section` 插槽注册页面；不会增加宿主 RPC，也不会修改设置骨架。产品文案仅中文：唯一的 `zh` 词典同时注册到两个内置语言席位上，切换语言不会出现裸 key。

页面以三行共十二张统计卡开场——总量（附周环比）、今日、近 7 天、带填充条的缓存命中率；四个计费桶及其占比；以及已知调用、会话数（附已计量数）、活跃天数（附连续活跃天数）和子代理占比。随后是洞察面板：带严重度色点的自动发现，覆盖缓存命中率健康度、周环比变化、上下文占用达到窗口 80% 的会话、显著的子代理占比、最繁忙时段。再往下是两根百分比单柱图（四个计费桶的 token 构成柱、提示词缓存命中率柱）、趋势图（按本地日 / 周 / 月堆叠；总量 / 输出 / 缓存命中率三种指标切换——命中率模式以固定 0–100% 轴绘制每桶命中率折线；token 指标叠加 7 日移动平均与峰值标记；范围开关可收窄为全部、近 7 / 30 / 90 天）、启发式上下文构成条（系统提示词 / 工具 Schema / 对话内容，汇总自带估算值的会话）、时段活跃度热力图（最繁忙格子描边并标注；悬停提示含已知调用数），以及明细列表——按工作区（含占总量比例）和按会话（持久标题投影、文本过滤、用量 / 最近排序、子代理与进行中徽标、agent preset 片段、上下文占用条并在窗口 80% 时告警）。点击会话行会打开该会话并关闭设置面板；该入口仅在组合提供 sessions 服务时渲染。

整个仪表盘通过应用设计 token 着色：插件在区块根节点定义自己的分段颜色，因此每个计费桶、柱子、单元格和提示点都使用主题调色板，而非浏览器默认色。UI 语言为中文时，卡片紧凑数值切换为万 / 亿单位。

报告是现有会话列表行的纯函数：插件在浏览器中聚合累计投影，用每个会话的 `updatedAt` 作为本地趋势和热力图的一次活跃标记，并把有非零用量的会话计为至少一次已知调用。页面没有写入路径，也没有推送失效；首次挂载、手动刷新、连接重置后重新加载，自动刷新开关打开时每 30 秒静默刷新一次。首次挂载以骨架屏填充。复制按钮把总量、每日序列与头部会话以纯文本写入剪贴板；导出按钮把会话明细下载为 RFC 4180 CSV；只要有已列出会话没有贡献投影，就会显示一条覆盖说明，避免把页面数字误当成完整的平台账单。

## Model Experience

无；本页是浏览器配置界面，不会向模型请求注入任何内容。

#### KV Cache effect

无；本包既不组装也不发送任何 provider 请求。

## Known Limitations and Deferred Work

- **只统计可见的 `session.list` 行** —— 未挂载 `tokenUsage` 投影，或某行没有投影值时，该行按零计入，不会触发历史读取。仪表盘会把这个缺口显示出来：没有可用投影的已列出会话单独计数（会话数卡、琥珀色覆盖说明、每行"未计入"标记），因此页面数字是实测子集，而非对全量的估计。
- **已删除的会话会离开列表** —— 在宿主侧被移除的会话，其计费总量不会出现在之后的任何报告中。
- **时间视图是提示性的，不是请求历史** —— 现有列表契约只有累计总量和一个 `updatedAt`，因此插件把会话总量放到这个活跃标记上，不虚构每次调用的时间。
- **已知调用是下限** —— 有非零用量的会话计为一次调用；现有投影没有精确调用数、回合数、步骤数和模型耗时，因此这些值为零或不可用。
- **用量数据不携带模型维度** —— `tokenUsage` 投影不包含模型或 provider，仪表盘最细只能拆到会话、工作区和来源。
- **缓存命中率是单一聚合值** —— 所有纳入会话的提示词侧占比，而非按请求的分布。
- **上下文数字是最后写入的启发式值** —— `contextPressure` 是被向前携带的最新采样，不是实时仪表；`contextBreakdown` 由 token-meter 估算器对表面计价，并非 provider 上报；缺少这些投影的会话不显示占用条，也不参与构成汇总。
- **标题与徽标受投影边界约束** —— 首个标题落地前的会话显示尾部 id 片段；`running` 只反映已附加的 agent，冷会话恒为空闲。
